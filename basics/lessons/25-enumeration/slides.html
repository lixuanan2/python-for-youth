人拨很累，计算机试起来飞快。这种办法叫枚举，也叫“穷举”：挨个列出来，一个个检查。

哪个数自己乘自己是 144？

每个 x 都检查一下：x * x 是 144 吗？是就输出。试到 12 时对上了。

range(1, 12) 只试到 11，不含 12。答案不在范围里，就一个也找不到，而且不报错。
枚举最要紧的是范围：答案可能出现的地方，一个都不能漏。

小测：1 到 100 都要试，range 怎么写？

枚举分三步

1定范围答案可能是哪些？一个都不能漏
2一个个试用 for 循环把它们挨个拿出来
3判断对不对用 if 检查，对上了就输出

想不出巧办法时，先想想能不能挨个试。题目给的条件，就是第 3 步的判断。

例题：鸡兔同笼

cage.py
heads = int(input())feet = int(input())for c in range(heads + 1):    r = heads - c    if c * 2 + r * 4 == feet:        print("鸡", c, "兔", r)

这节课常见的三种错误

划线的写法只阅读，不要照抄

range(heads)不报错漏了“全是鸡”这一种
range(1, heads + 1)不报错漏了“一只鸡也没有”
循环里写“没有答案”不报错每试错一次就说一遍

枚举的错大多不报错，只是少了答案或多了废话。用两头的数据试一试：全是鸡、全是兔。

找错：10 个头 20 只脚，全是鸡，却没输出

# 自己挑战

百钱买百鸡

一道一千多年前的古题：公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元 3 只。读入 n（1 到 300 的整数），用 n 元正好买 n 只鸡，小鸡要整 3 只地买。
每种买法输出一行，公鸡从少到多，公鸡一样时母鸡从少到多。一种也没有就输出“没有答案”。

输入
100
输出
公鸡 0 母鸡 25 小鸡 75
公鸡 4 母鸡 18 小鸡 78
公鸡 8 母鸡 11 小鸡 81
公鸡 12 母鸡 4 小鸡 84
▶ 在 IDE 开始写

先自己写，卡住了再翻下一页。

卡住了？一次看一条提示

提示 1定范围：公鸡最多 n // 5 只，母鸡最多 n // 3 只。用第 18 课的两层循环，外层试公鸡，内层试母鸡。

提示 2只数凑满 n，小鸡就是 n - 公鸡 - 母鸡。小鸡不能是负数，还要是 3 的倍数：% 3 == 0。

提示 3再检查钱：公鸡 × 5 + 母鸡 × 3 + 小鸡 // 3 等于 n 就输出。没找到过就说“没有答案”，和动手题一样。
