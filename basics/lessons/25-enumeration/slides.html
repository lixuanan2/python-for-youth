feet = int(input())
for c in range(heads, -1, -1):

# 自己挑战

  
百钱买百鸡

  
一道一千多年前的古题：公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元 3 只。读入一个整数 n，用 n 元正好买 n 只鸡，小鸡要整 3 只地买。
每种买法输出一行，公鸡从少到多，公鸡一样时母鸡从少到多。一种也没有就输出“没有答案”。

  
输入
100
输出
公鸡 0 母鸡 25 小鸡 75
公鸡 4 母鸡 18 小鸡 78
公鸡 8 母鸡 11 小鸡 81
公鸡 12 母鸡 4 小鸡 84

  
▶ 在 IDE 开始写
先自己写，卡住了再翻下一页。

  







  
卡住了？一次看一条提示

  

    
提示 1定范围：公鸡最多 n // 5 只，母鸡最多 n // 3 只。用第 18 课的两层循环，外层试公鸡，内层试母鸡。

    
提示 2只数凑满 n，小鸡就是 n - 公鸡 - 母鸡。小鸡不能是负数，还要是 3 的倍数：% 3 == 0。

    
提示 3再检查钱：公鸡 × 5 + 母鸡 × 3 + 小鸡 // 3 等于 n 就输出。没找到过就说“没有答案”，和动手题一样。

  

  









  
说得清吗？

  

    
Q1鸡兔同笼为什么只试鸡，不再套一层试兔？　头数定了，兔就是 heads - c，一层就够。

    
Q2找到答案以后不停下，接着试完，结果有什么不同？　输出一样，只有一种答案；只是多试了几次。

    
Q3找出 1 到 100 里是 7 的倍数、个位又是 3 的数，怎么写？　for x in range(1, 101): 里面 if x % 7 == 0 and x % 10 == 3: print(x)

  

  
先自己说一说，再翻下一步看答案。

for x in range(1, 101):1 到 100 挨个试

    
if 条件:对上了就输出

    
range(heads + 1)从 0 到 heads，两头都要试

    
found = False记着找到过没有

    
两个未知数两层循环，或者用一个算出另一个
