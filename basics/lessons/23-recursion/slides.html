递归入门：函数调用自己

学完你能让函数调用自己，把一件大事拆成一样的小事，一层层做完。

像打开套娃

打开一个套娃
里面还有一个
打开它
再小一号
打开到最小的那个
打不开，停

每次做的事都一样：打开。只是套娃一次比一次小，小到最后一个就停下。
函数也能这样：在函数里调用自己，每次处理小一点的问题，小到一眼能答就停。这叫递归。

函数调用自己：倒数发射

countdown.py
def countdown(n):    if n == 0:        print("发射！")    else:        print(n)        countdown(n - 1)countdown(3)

countdown(3) 先输出 3，然后第 6 行调用自己：countdown(2)。

countdown(2) 输出 2，再调用 countdown(1)……每调用一次，n 小 1。

到了 countdown(0)，n == 0 成立，输出“发射！”，不再调用自己，停下。

3
2
1
发射！

猜一猜：先调用自己，再输出，顺序会怎样？

up.py
def up(n):    if n > 0:        up(n - 1)        print(n)up(3)

和倒数比，print 和调用自己换了位置。
输出 3 2 1，还是 1 2 3？

1
2
3

up(3) 要先等 up(2) 全部做完，才轮到 print(3)。up(2) 又要先等 up(1)……
所以最里面的 up(1) 最先输出。到了 up(0)，n > 0 不成立，什么也不做。

递归要有两件事

出口：什么时候停

if n == 0:

小到一眼能答，就不再调用自己

变小：每次近一步

countdown(n - 1)

每调用一次，离出口近一点

少了哪一件，函数都会一直调用自己。调用的层数太多，Python 就停下，报 RecursionError：递归太深了。
写递归，先想好这两件事。

例题：从 1 加到 n

total.py
def total(n):    if n == 1:        return 1    return n + total(n - 1)print(total(int(input())))

输入 4。1 加到 4，就是 4 加上“1 加到 3”。“1 加到 3”是个小一号的同样问题。

total(3) 又要 total(2)，total(2) 又要 total(1)。每一层都停在这里，等下一层的结果。

total(1) 是出口：1 加到 1 就是 1，直接 return 1，不再调用自己。

结果一层层交回去：2 + 1 是 3，3 + 3 是 6，4 + 6 是 10。最后输出 10。

total(4)4 + total(3)
total(3)3 + total(2)
total(2)2 + total(1)
total(1)1

1 → 3 → 6 → 10

比如 2026：2 + 0 + 2 + 6 = 10。不许把 n 变成字符串，只用数和递归。

输入

输出

卡住了？一次看一条提示

提示 1只有一位数时（n < 10），各位加起来就是它自己。这就是出口。

提示 2n % 10 是个位（第 3 课学过），n // 10 是去掉个位以后剩下的数（第 7 课用过）。

提示 3各位之和 = 个位 + 剩下那个数的各位之和。后面这一半，就是调用自己，n 每次少一位。
