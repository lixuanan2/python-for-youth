写程序的时候，你不知道别人要猜几次，range 里填几都不对。
这时要换一种说法：只要还没猜对，就继续。

while：条件成立就继续

count.py
i = 1while i <= 3:    print(i)    i = i + 1

1 <= 3 成立，输出 1，i 变成 2。

回到 while 再问：2 <= 3 成立，输出 2，i 变成 3。

再问：3 <= 3 成立，输出 3，i 变成 4。

再问：4 <= 3 不成立，循环结束。

while 是“当……的时候”。条件成立就运行缩进的行，
运行完回到 while 再问一次。这一行末尾也有冒号。

两段只差一个词。各输出几行？

if 只问一次，成立就做一遍。while 做完还会回来再问。

写 while 要想好三件事

1开始值i = 1
变量从哪里开始
2继续条件i <= 3
什么时候还要继续
3更新i = i + 1
每一遍怎么往前走

这三件事 for 里的 range 帮你管着，用 while 就要自己写。

小测：最后一行输出几？

输出几？
i = 1while i <= 3:    i = i + 1print(i)

同一件事，两种写法

for：从 1 数到 n

n = int(input())
for i in range(1, n + 1):
    print(i)

while：从 1 数到 n

n = int(input())
i = 1
while i <= n:
    print(i)
    i = i + 1

知道要重复几次，用 for 更短。
要等一件事发生才停，比如猜对、读到 0，用 while。

例题：猜对才结束

guess.py
secret = 7guess = int(input())while guess != secret:    print("不对，再猜")    guess = int(input())print("猜对了")

输入 3，3 != 7 成立，说不对，再读下一个。

输入 9，9 != 7 成立，说不对，再读下一个。

输入 7，7 != 7 不成立，循环结束，说猜对了。

input 写了两次：循环前读第一次，循环里读下一次。

划线的写法只阅读，不要照抄

while i <= 3SyntaxError末尾要加冒号
