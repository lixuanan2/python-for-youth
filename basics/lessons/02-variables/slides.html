▶ 在 IDE 打开
age12

print(age) 不加引号，输出的是盒子里的 12，不是 age 这三个字母。

这个等号不是“相等”

数学里的 =

3 + 1 = 4

两边的值相等。

Python 里的 =

age = 12

把右边的 12 放进左边的 age。

这个动作叫赋值。读代码时从右往左读：把 12 放进 age。

给盒子起个好名字

可以

age
my_age
score2

不可以

2age
my age
my-age

名字里用字母、数字和下划线，不能用数字开头，也不能有空格。
if、else 这些 Python 自己要用的词不能当名字，print、input 也别用。
age 和 Age 是两个不同的变量。名字最好一看就懂：score 比 a 好。

小测：哪个名字能用？

盒子里的东西分种类

int

12

整数，比如年龄
float

2.5

小数，比如价格
str

"Ming"

文字，比如名字
bool

True

真假，比如过关了吗

这就是数据类型。写 age = 12 时不用说明类型，Python 看右边的值就知道。

把文字和数字放在一起说

intro.py
age = 12print("我今年", age, "岁")print("我今年" + str(age) + "岁")

文字和整数不能直接用 + 连起来，会报 TypeError。
办法一：用逗号，print 会加空格。
办法二：用 str() 把数字变成文字，再拼接。
