猜一猜：数据换了顺序，结果一样吗？

  
order.py


def show(a, b):
    print(a - b)
show(10, 3)
show(3, 10)

  

    
7
-7

  

  

      
两次调用给的都是 10 和 3，只是顺序不同。

      
不一样。数据按顺序一个对一个：第一个给 a，第二个给 b。

      
show(3, 10) 时 a 是 3、b 是 10，算出 -7。调用时要按参数的顺序给。

猜一猜：函数里用 print，能接着算吗？

  

    
函数里 print
def f():
    print(5)
x = f()
print(x)
5
None

    
函数里 return
def g():
    return 5
y = g() + 1
print(y)
6

  

  

      
左边的 x 拿到了什么？

      
print 只是显示，没有交回。没有 return 的函数交回 None，意思是“什么也没有”。
None 不能拿来算，f() + 1 会报错。要接着用结果，就用 return。
