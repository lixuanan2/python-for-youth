上节课的函数像只会放一首歌的音乐盒。这节课给函数开两扇门：
进门的叫“参数”，把数据带进去；出门的叫“返回值”，把算好的结果带回来。

参数：调用时把数据带进去

greet.py
def greet(name):    print("你好", name)greet("小明")greet("小红")

括号里的 name 就是参数，像函数自己的一个变量，现在还是空的。

调用 greet("小明")，"小明" 被放进 name，函数说“你好 小明”。

再调用时放进 "小红"。同一个函数，给的不一样，做的就不一样。

猜一猜：数据换了顺序，结果一样吗？

order.py
def show(a, b):    print(a - b)show(10, 3)show(3, 10)
7
-7

两次调用给的都是 10 和 3，只是顺序不同。

不一样。数据按顺序一个对一个：第一个给 a，第二个给 b。
show(3, 10) 时 a 是 3、b 是 10，算出 -7。调用时要按参数的顺序给。

return：把结果交回来

area.py
def area(w, h):    return w * hs = area(3, 4)print(s)print(area(2, 5))

第 3 行调用 area，把 3 和 4 带进去。

return 的意思是“返回”。函数算出 12，交回调用的地方，整个 area(3, 4) 就变成 12，存进 s。

交回来的数，可以存起来、输出，也可以直接放进 print 里。

猜一猜：函数里用 print，能接着算吗？

函数里 print

def f():
    print(5)
x = f()
print(x)

5
None

函数里 return

def g():
    return 5
y = g() + 1
print(y)

6

左边的 x 拿到了什么？

print 只是显示，没有交回。没有 return 的函数交回 None，意思是“什么也没有”。
None 不能拿来算，f() + 1 会报 TypeError。要接着用结果，就用 return。

bigger.py
def bigger(a, b):    if a > b:        return a    return bprint(bigger(3, 8))print(bigger(9, 2))

bigger(3, 8)：3 不比 8 大，跳过 if，走到最后一行，交回 b，也就是 8。

bigger(9, 2)：9 比 2 大，交回 9，函数马上结束，最后一行轮不到。不用写 else。
