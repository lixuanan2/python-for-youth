f-string：把话说得整整齐齐

学完你能把变量直接放进句子里，让小数只留两位，把时间显示成 01:05:09。

输出总是不太整齐

print("明年你", age + 1, "岁")
明年你 13 岁
print(10 / 3)
3.3333333333333335

逗号会多出空格，小数又长得看不完。写成绩单、小票、时钟，都想要整整齐齐的输出。
这节课学 f-string：在引号前面加一个 f，就能把变量直接写进句子里，还能管住小数有几位。

生活里：超市小票、电子钟都要整整齐齐。先想一想：怎样把 5 分 9 秒显示成 05:09？

引号前面加 f

hello.py


name = "小明"
age = 12
print("{name}今年{age}岁")

  

    
小明今年12岁

    
小明今年12岁
明年13岁

猜一猜：忘了写 f，会输出什么？
只少了一个字母 f，会报错吗？

    
{name}今年{age}岁
▶ 在 IDE 验证

  

  

    
f 是 format（格式）的第一个字母。加了 f，引号里的大括号 { } 就会换成变量的值。
没有逗号，也就没有多余的空格。

    
大括号里还能写算式。{age + 1} 先算出 13，再放进句子里。

    
不报错，原样输出。没有 f，它就是一串普通的文字，大括号也只是普通的符号。
看到屏幕上出现大括号，先检查引号前面有没有 f。

不够两位，前面补 0

  
time.py


m = 5
s = 9
print(f"{m}:{s}")
print(f"{m:02d}:{s:02d}")

  

      
5 分 9 秒，直接输出成 5:9，不像钟表上的样子。

      
:02d 的意思是“整数，至少 2 位，不够前面补 0”。d 表示整数。12 本来就有两位，就不补。

    

  ▶ 在 IDE 打开

卡住了？一次看一条提示

  

    
提示 1一小时是 3600 秒。秒数 // 3600 就是几点。

    
提示 2去掉整小时，剩下 秒数 % 3600，再 // 60 是分；秒数 % 60 是秒。第 3 课的整除和求余又用上了。

    
提示 3三段都用 :02d 补零，中间用冒号连起来，放在一个 f-string 里。
