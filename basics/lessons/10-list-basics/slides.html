一个变量是一个盒子，只装一个数。列表是一排盒子，每个盒子有编号，
编号从 0 开始。想要哪个，报编号就能拿到。

第一个列表

basics.py
scores = [80, 95, 70]print(scores)print(scores[0])print(len(scores))

方括号里用逗号隔开，三个分数排成一排。整个列表也能直接输出。

名字后面加方括号写编号，叫“下标”。下标 0 是第一个。

len() 数一数列表里有几个。

too_far.py（只阅读）
scores = [80, 95, 70]print(scores[3])
屏幕上
IndexError: list index
out of range

三个分数，下标只有 0、1、2。要 [3] 就超出了范围，程序报 IndexError，停下来。
报错的意思是：下标超出了列表的范围。看到它，先数一数列表里有几个。

倒着数：-1 是最后一个

ends.py
scores = [80, 95, 70]print(scores[-1])print(scores[-2])print(len(scores))

下标写负数，就是从后往前数。-1 是最后一个。

-2 是倒数第二个。倒数第 k 个就写 -k。

有 3 个，所以正着数最后一个的下标是 len - 1，也就是 2。

append：往后面加一个

append.py
scores = []scores.append(80)scores.append(95)print(scores)print(len(scores))

[] 是空列表，一个盒子也没有。

append 的意思是“追加”。在最后面接上一个盒子，放进 80。

再接一个 95。现在有 2 个，输出 [80, 95] 和 2。

例题：取第 k 个

kth.py
n = int(input())scores = []for i in range(n):    scores.append(int(input()))k = int(input())print(scores[k - 1])

输入 3。先准备一个空列表，就像累加前先写 total = 0。

循环 3 遍，每遍读一个分数接到后面：80、95、70。

最后一行读入 k，想要第 2 个。

第 2 个的下标是 2 - 1，也就是 1，输出 95。

猜一猜：把 scores = [] 放进循环会怎样？

inside.py（只阅读）
n = int(input())for i in range(n):    scores = []    scores.append(int(input()))print(scores)

依次输入 3、80、95、70，最后输出什么？

[70]

每一遍都换一个新的空列表，前面存的全丢了，只剩最后一个 70。
和累加一样：准备工作放在循环前面，只做一次。
