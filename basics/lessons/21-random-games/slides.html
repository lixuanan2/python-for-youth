Python 有一盒叫 random 的工具，能帮程序“随便挑一个”。

randint：掷骰子

dice.py
import randomprint(random.randint(1, 6))print(random.randint(1, 6))print(random.randint(1, 6))

random 是“随机”，先 import 借来。
randint(1, 6) 从 1 到 6 里随机挑一个整数。

第 6 课学过，range 不含终点。randint 也一样吗？

不一样。randint 两头都算：1 和 6 都可能出现，正好是一颗骰子。
range 不含终点，randint 含终点，这两个最容易记混。

choice：从列表里抽一个

draw.py
import randomnames = ["小明", "小红", "小刚"]pick = random.choice(names)print(pick, "来回答")

choice 的意思是“挑选”。括号里放一个列表，它随机抽出其中一个。
抽签、点名、电脑出拳，都用它。

seed：让随机可以重来

seed.py
import randomrandom.seed(7)print(random.randint(1, 100))print(random.randint(1, 100))

seed 是“种子”。随机数是从种子一步一步算出来的，种子一样，后面挑出的数就一样。

种子是 7，每次运行都先出 42、再出 20。全班用同一个种子，就能对答案。真玩游戏时，不写 seed。
