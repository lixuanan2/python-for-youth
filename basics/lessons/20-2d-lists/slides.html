一张成绩表怎么存？

语文　数学　英语
小明  90  80  70
小红  60  85  95

每个人有三科分数，一个人一行。
一行可以用一个列表存：[90, 80, 70]。

好几行呢？再用一个大列表，把每一行装进去。列表里装列表，叫“二维列表”，
就像一张有行有列的表格。

第一张表

grid.py
scores = [[90, 80, 70],          [60, 85, 95]]print(scores[0])print(scores[1][2])print(len(scores))

scores[0] 是第一行，整行是一个列表：小明的三科。

两个下标：先找行，再找列。[1][2] 是第二行的第三个，小红的英语 95。

len(scores) 数的是有几行：2 行。

是 60。先 [1] 拿到第二行 [60, 85, 95]，再 [0] 拿这一行的第一个。
读法：“第 1 行、第 0 列”，行和列的编号都从 0 开始。

两层循环，走遍每一格

each_cell.py
grid = [[1, 2, 3], [4, 5, 6]]for row in grid:    for x in row:        print(x, end=" ")    print()

外层一次拿一整行，内层再把这一行一个一个拿出来，用空格隔开。

一行看完换行。和上上节课画星星一样：外层管行，内层管每行里的格子。

例题：每个人的总分

row_totals.py
n = int(input())table = []for i in range(n):    row = []    for w in input().split():        row.append(int(w))    table.append(row)for i in range(n):    print(i + 1, sum(table[i]))

每读一行，比如 90 80 70，用 split 切开，一个一个变成整数，装进 row，再把这一行放进表里。

表存好了。每一行是一个人，用 sum 算这一行的和。

change_cell.py

小测：grid 有几行、几列？

grid = [[1, 2, 3], [4, 5, 6]]

这节课常见的三种错误

划线的写法只阅读，不要照抄

grid[2]IndexError只有两行，行号是 0 和 1
grid[1, 2]TypeError两个下标各用一对方括号
grid[j][i]拿错格子先行后列，别写反

行和列写反时，表格是方的就不报错，只是拿错了格子；不是方的才会报错。
