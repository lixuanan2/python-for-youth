缩进的行归 for 管，每一遍都运行。
不缩进的行不归它管，等循环结束后只运行一次。

循环里放 if：一个一个筛

even.py
n = int(input())for i in range(1, n + 1):    if i % 2 == 0:        print(i)

输入 4。i 是 1，1 % 2 是 1，条件不成立，跳过。

i 是 2，2 % 2 是 0，条件成立，输出 2。

i 是 3，3 % 2 是 1，跳过。

i 是 4，4 % 2 是 0，输出 4。循环结束。

for 负责一个一个看，if 负责挑出想要的。
if 缩进 4 个空格，它下面的 print 要再缩进 4 个。

这节课常见的三种错误

划线的写法只阅读，不要照抄

for i in range(3)SyntaxError末尾要加冒号
for i in 3:TypeError要写 range(3)
for 下一行没缩进IndentationError缩进 4 个空格

要小心：倒着数忘了写 -1，比如 range(5, 0)，不报错，只是一遍也不运行。
