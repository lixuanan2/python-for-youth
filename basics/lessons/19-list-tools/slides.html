sum、max、min

tools.py
scores = [80, 95, 70]print(sum(scores))print(max(scores))print(min(scores))print(sum(scores) / len(scores))

sum 把列表里的数全加起来：245。

max 找最大的，min 找最小的。

总和除以个数，就是平均分。除不尽时，小数会很长。

sorted：排好顺序

sorted.py
scores = [80, 95, 70]print(sorted(scores))print(sorted(scores, reverse=True))print(scores)

sorted 交回一个从小到大排好的新列表。

加上 reverse=True，就从大到小。reverse 的意思是“反过来”。

原来的 scores 没变。sorted 是照着排一份新的。

▶ 在 IDE 打开
从小[70, 80, 95]
从大[95, 80, 70]
原来[80, 95, 70]

猜一猜：sort 和 sorted 有什么不同？

sorted(a)

a = [3, 1, 2]
b = sorted(a)
print(a, b)

[3, 1, 2] [1, 2, 3]

a.sort()

a = [3, 1, 2]
x = a.sort()
print(a, x)

[1, 2, 3] None

一个写在括号外面，一个用点接在列表后面。

sorted 排一份新的交回来，原来的不动。a.sort() 直接把 a 自己排好，什么也不交回，
所以 x 拿到 None。想要新列表用 sorted，想直接改原来的用 sort。
