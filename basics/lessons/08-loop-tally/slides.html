循环每一遍读到一个分数，下一遍就换成新的了，前面的数留不住。
办法就像存钱罐：放一个变量在循环外面，每一遍往里加一点，到最后再打开看。

累加：一遍加一点

sum_three.py
total = 0for i in range(1, 4):    total = total + iprint(total)

total 从 0 开始。i 是 1，0 + 1 得 1。

i 是 2，1 + 2 得 3，放回 total。

i 是 3，3 + 3 得 6，放回 total。

循环结束，输出 total，也就是 1 + 2 + 3 的和。

猜一猜：放错位置会怎样？

total = 0 放进循环

for i in range(1, 4):
    total = 0
    total = total + i
print(total)

3

print 放进循环

total = 0
for i in range(1, 4):
    total = total + i
    print(total)

1 3 6

和上一页比，都只挪了一行。各输出什么？

左边每一遍都把存钱罐倒空，只留下最后的 3。
右边每加一次就输出一次，一共三行，每个数占一行。

累加要放对三个位置

1循环前total = 0
准备好，只做一次
2循环里total = total + i
每一遍加一点
3循环后print(total)
全部加完再输出

看代码的缩进，就能看出每一行在哪个位置。

更新有个简写：+=

total += i就是 total = total + i
count += 1就是 count = count + 1
i -= 1就是 i = i - 1

读作“加上”：total 加上 i。两种写法结果一样，后面都用短的这种。
注意加号在等号前面。
