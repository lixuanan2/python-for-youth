切片：截出一段

slice.py
word = "Python"print(word[0:2])print(word[2:5])

方括号里写“起点:终点”，从起点截到终点前面。[0:2] 是下标 0 和 1：Py。

[2:5] 是下标 2、3、4：tho。和 range 一样，不含终点。
截出几个字？终点减起点：5 - 2 = 3。

▶ 在 IDE 打开
[0:2]Py
[2:5]tho

猜一猜：起点或终点不写，会截出什么？

不写起点

word[:3]

Pyt

不写终点

word[3:]

hon

word 还是 "Python"。

不写起点，就从头开始：前 3 个字。不写终点，就截到最后。
前 k 个写 word[:k]，后 k 个写 word[-k:]。

字符串里的字不能直接换

change.py（只阅读）
word = "Python"word[0] = "J"
屏幕上
TypeError: 'str' object does not support item assignment

列表的盒子能换，字符串的不能。想要一个新词，就拼一个新的字符串：

new.py
new = "J" + word[1:]print(new)    # Jython

这节课常见的三种错误

划线的写法只阅读，不要照抄

word[6]IndexError6 个字，最大下标是 5
word[0] = "J"TypeError不能换，要拼一个新的
word[1:3]不报错是 yt，终点 3 不算

切片截少了一个最常见。截之前先数：终点减起点，就是截出几个字。

找错：banana 里怎么一个 a 也没有？
