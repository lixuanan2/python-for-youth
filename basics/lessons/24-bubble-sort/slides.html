# 自己挑战

  
排队换了几次

  
体育课按身高从矮到高排队，每次只能让挨着的两个人换位置。第一行读入人数 n，接下来 n 行，每行一个整数身高。
用冒泡排序排好，输出两行：排好的列表；一共换了几次。一样高的两个人不用换，不算一次。

  
依次输入
4
5
2
4
1
输出
[1, 2, 4, 5]
5

  
▶ 在 IDE 开始写
先自己写，卡住了再翻下一页。

  







  
卡住了？一次看一条提示

  

    
提示 1读入和排序都可以照例题写。去掉每轮的 print，排好以后再输出一次列表。

    
提示 2准备一个计数器，从 0 开始。真的换了才加 1，所以加 1 要写在 if 里面。

    
提示 3两个人一样高时不用换，比较用 >，不要用 >=。试试本来就排好的队，应该换 0 次。

  

  









  
说得清吗？

  

    
Q1为什么内层是 range(n - 1 - r)？　后面 r 个已经站好，不用再比；再减 1 是因为要比 a[j + 1]。

    
Q2比较写成 >=，排出来的结果和换的次数有什么不同？　结果一样，但一样大的也换，换的次数变多。

    
Q3只想把最大的数放到最后，要写几轮？　一轮就够：for j in range(n - 1) 比一遍，最大的就到了最后。

  

  
先自己说一说，再翻下一步看答案。

  







  
速查卡

  

    
a, b = b, a一行交换，谁也不会被盖掉

    
a[j], a[j + 1] = a[j + 1], a[j]交换列表里挨着的两个

    
for r in range(n - 1):n 个数比 n - 1 轮

    
for j in range(n - 1 - r):每轮少比一对

    
if a[j] > a[j + 1]:从小到大；换成 < 就从大到小

  

  







  
这些后面再学

  

    
选择排序每轮找出最小的，放到最前面

    
插入排序像整理手里的扑克牌，一张张插进去

    
更快的排序数很多时冒泡太慢，sorted 用的是更快的办法
