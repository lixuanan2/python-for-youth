排队时，老师常让挨着的两个人比一比：前面的高，就换个位置。一遍遍比下去，队伍就整齐了。
这节课用同样的办法写一个排序程序。高的数会像水里的泡泡一样往后冒，所以叫冒泡排序。

真的能换过来吗？

列表里的两个位置也能这样换：

a[0], a[1] = a[1], a[0]

▶ 在 IDE 打开

第 3 行 a 变成 5，原来的 3 就被盖掉了。第 4 行 b = a，拿到的也是 5。
就像两杯饮料互换，直接倒过去会混在一起，得先找个空杯子。

Python 一行就能交换。a, b = b, a：先把右边的 b 和 a 都看好，
再同时放进左边，谁也不会被盖掉，不用找空杯子。

从头到尾比一轮

one_pass.py
a = [5, 2, 4, 1]for j in range(3):    if a[j] > a[j + 1]:        a[j], a[j + 1] = a[j + 1], a[j]    print(a)

4 个数挨着比，只有 3 对，所以是 range(3)。
按“播放”看一轮：最大的数像泡泡，一路冒到最后。

例题：一轮轮比，直到排好

▶ 在 IDE 打开
bubble.py
n = int(input())a = []for k in range(n):    a.append(int(input()))for r in range(n - 1):    for j in range(n - 1 - r):        if a[j] > a[j + 1]:            a[j], a[j + 1] = a[j + 1], a[j]    print(a)

站好的不用再比，所以内层是 range(n - 1 - r)。
输入 4 个数，比 n - 1 也就是 3 轮，一定排好。

用冒泡排序排好，输出两行：排好的列表；一共换了几次。一样高的两个人不用换，不算一次。

说得清吗？

Q1怎样交换两个变量？　a, b = b, a，一行同时换。

Q2比完一轮，哪个站对了位置？　最大的到了最后。

Q3为什么内层是 range(n - 1 - r)？　后面 r 个已经排好，不用再比；再减 1 是因为要比 a[j + 1]。

先自己说一说，再翻下一步看答案。

速查卡

a, b = b, a一行交换，谁也不会被盖掉
a[j], a[j + 1] = a[j + 1], a[j]交换列表里挨着的两个
for r in range(n - 1):n 个数比 n - 1 轮
for j in range(n - 1 - r):每轮少比一对
if a[j] > a[j + 1]:从小到大；换成 < 就从大到小

插入排序像整理手里的扑克牌，一张张插进去
更快的排序数很多时冒泡太慢，sorted 用的是更快的办法
