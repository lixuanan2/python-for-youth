一输错，程序就停了

程序问你几岁，你输入
十二
屏幕上
ValueError

用汉字写的“十二”，int() 转换不了，程序报错，后面的话一句也不说了。
用的人难免输错。这节课学 try 和 except：先接住报错，提醒一句，程序接着运行。

先认出报错的名字

Traceback (most recent call last):
  File "age.py", line 1, in <module>
    age = int(input())
ValueError: invalid literal
for int() with base 10: '十二'

第 1 课学过：红字从最后一行读。

ValueError 是这种错的名字，意思是“值不对”。

'十二' 是它读到的内容。

每种报错都有自己的名字。要接住哪种错，就要先知道它叫什么。
int() 转换不了时，报的就是 ValueError。

try：先试试，出错就接住

age.py
try:    age = int(input())    print("明年你", age + 1, "岁")except ValueError:    print("请输入整数")

try 的意思是“试一试”。下面缩进的几行照常运行，就像 if 下面的缩进一样。

输入 12，一切顺利：两行都运行，输出“明年你 13 岁”。except 下面的不运行。

输入“十二”，int() 报 ValueError。except ValueError 接住它，改为运行这句提醒。

例题：一直问到输对为止

retry.py
done = Falsewhile not done:    try:        age = int(input())        done = True    except ValueError:        print("不是整数，再输一次")print("明年你", age + 1, "岁")

done 记着“输对了没有”。一开始是 False，not done 成立，进入循环。

输入 abc：出错，done = True 被跳过。提醒一句，回到 while。

输入 3.5：又出错，done 还是 False，再问一次。

输入 12：转换成功，done 变成 True，循环结束，说出结果。

卡住了？一次看一条提示

提示 1先读入 n，准备两个计数器：总和与不是整数的行数，都从 0 开始。用 for 循环读 n 行。
