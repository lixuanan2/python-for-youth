用汉字写的“十二”，int() 转换不了，程序报错，后面的话一句也不说了。
用的人难免输错。这节课学 try 和 except：先接住报错，提醒一句，程序接着运行。

先认出报错的名字

Traceback (most recent call last):
  File "age.py", line 1, in <module>
    age = int(input())
ValueError: invalid literal
for int() with base 10: '十二'

第 1 课学过：红字从最后一行读。

ValueError 是这种错的名字，意思是“值不对”。

'十二' 是它读到的内容。

每种报错都有自己的名字。要接住哪种错，就要先知道它叫什么。
int() 转换不了时，报的就是 ValueError。

done = False
while not done:
    try:
        age = int(input())
        done = True
    except ValueError:
        print("不是整数，再输一次")
print("明年你", age + 1, "岁")

卡住了？一次看一条提示

  

    
提示 1先读入 n，准备两个计数器：总和与不是整数的行数，都从 0 开始。用 for 循环读 n 行。

    
提示 2每行先用 input() 存起来，不要马上 int()。在 try 里转换成整数，加进总和。

    
提示 3转换不了就会走到 except ValueError，在那里把行数加 1。循环结束后再输出两行。
