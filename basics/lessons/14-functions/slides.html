复制粘贴能做到，可是一要改就得每处都改，漏一处就错。
办法是给这几行起个名字，叫“函数”。要用的时候叫它的名字，改也只改一处。

def：定义一个函数

hello.py
def hello():    print("你好！")    print("欢迎来上课")hello()hello()

def 是“定义”。前三行只是把两句话装进一个叫 hello 的盒子，这时什么也不输出。

名字后面加括号，叫“调用”。程序跳进函数，把两句话输出一遍。

再调用一次，再输出一遍。写一次，用两次。

猜一猜：先调用，再定义，行吗？

order.py（只阅读）
hello()def hello():    print("你好！")
屏幕上
NameError: name 'hello' is not defined

程序从上往下一行一行地走。走到第 1 行时，它认识 hello 吗？

不行。第 1 行时还没读到定义，程序不认识 hello，报 NameError。
先定义，后调用。定义一般都写在程序最上面。

函数里也能放循环

def countdown():    for i in range(3, 0, -1):        print(i)    print("发射！")countdown()print("再来一次")countdown()

函数体可以是好几行，循环、判断都能放。看缩进：发射在循环外，函数里。
