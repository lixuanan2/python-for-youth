红字不可怕：从最后一行读

Traceback (most recent call last):
  File "hello.py", line 1, in <module>
    Print("hi")
    ^^^^^
NameError: name 'Print' is not defined.
Did you mean: 'print'?

line 1：错在第 1 行。

NameError 表示 Python 不认识这个名字。

Did you mean 是它在猜：你是想写 print 吗？

程序报错很正常，程序员每天都会遇到。
红字是 Python 在告诉你哪里出了问题，先看最后一行，再看行号。

三种最常见的错误

划线的写法只阅读，不要照抄

Print("hi")NameErrorprint 全部小写
print(“hi”)SyntaxError换成英文引号
int() 读到 3 4ValueError一个 int() 只转换一个数

只写 input() 读入 3 4 没问题，转不了的是 int()。
