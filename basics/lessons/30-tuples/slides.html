元组能把几个值打成一包，当成一个东西传来传去，用的时候再拆开。

圆括号打包，逗号隔开

point.py
p = (3, 5)print(p)print(p[0], p[1])x, y = pprint(x + y)

元组用圆括号写，像列表一样有下标：p[0] 是 3，p[1] 是 5。

x, y = p 叫拆包：左边几个名字，就按顺序拆成几个。第 24 课的 a, b = b, a 用的也是它。

屏幕上
TypeError

报 TypeError：元组不支持给某一格重新赋值。元组打好包，就不能给哪一格重新赋值，比列表“牢”。
要换一个点，就整个重新写：p = (9, 5)。这样也不容易被别的代码不小心改掉。

函数一次交回两个

low_high.py
def low_high(nums):    return min(nums), max(nums)low, high = low_high([7, 2, 9, 4])print("最低", low)print("最高", high)

return 后面用逗号写两个值，其实是打成一个元组 (2, 9) 交回去。

调用的地方左边写两个名字，就把这一包拆开：low 拿到 2，high 拿到 9。

列表里装着一对一对

pairs.py
students = [("小明", 90), ("小红", 85)]for name, score in students:    print(f"{name}：{score} 分")

列表里每一格都是一个元组：名字和分数绑在一起，不会错位。

for 后面写两个名字，每次拿出一对，顺手就拆开了：第一次 name 是小明，score 是 90。
