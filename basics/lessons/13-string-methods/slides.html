strip：去掉两头的空格

strip.py
name = "  小明  "print("[" + name + "]")clean = name.strip()print("[" + clean + "]")

空格看不见，在两边加上方括号，就能看出前后各有两个空格。

strip 的意思是“剥掉”。它做出一个去掉两头空格的新字符串，存进 clean。中间的空格不动。

▶ 在 IDE 打开
name[ 小明 ]
clean[小明]

猜一猜：strip 以后，name 变了吗？

guess.py
name = "  小明  "name.strip()print("[" + name + "]")

?

先在纸上写下你的答案。

[ 小明 ]

没变。上节课说过，字符串里的字不能换。strip 不改 name，只做出一个新字符串，
没存起来就丢了。要么存进新变量，要么写 name = name.strip()。

▶ 在 IDE 验证

replace：换词

replace.py
s = "我爱猫，猫爱我"print(s.replace("猫", "狗"))print(s)

括号里先写旧的，再写新的。所有的“猫”都换成了“狗”。

再输出 s，还是原来的样子。replace 也是做出新字符串，不改原来的。

▶ 在 IDE 打开
第 2 行我爱狗，狗爱我
第 3 行我爱猫，猫爱我

猜一猜：count 数出来是几？

数 banana 里的 a

"banana".count("a")

3

数 aaaa 里的 aa

"aaaa".count("aa")

2

count 数一数某个词出现了几次。右边好好想：aaaa 里能找出几个 aa？

右边是 2，不是 3。count 从左往右找，找到一个 aa 就跳过它，接着往后找，用过的字不再用。
上节课自己写了五行才数出几个 a，现在一句就行。

split：切成列表

split.py
line = "小明 小红 小刚"names = line.split()print(names)print(len(names))

split 的意思是“切开”。括号里不写，就按空格切，切出来是一个列表。

切出来是列表，列表会的它都会：len 数个数、下标、for 遍历。按逗号切就写 split(",")。

▶ 在 IDE 打开
names['小明', '小红', '小刚']
len3

猜一猜：中间有两个空格，切出来一样吗？

括号里不写

"a  b".split()

['a', 'b']

写一个空格

"a  b".split(" ")

['a', '', 'b']

a 和 b 中间连着两个空格。

不写，就把连着的空格当成一处，两头的空格也不管。
写了 " "，就每遇到一个空格切一刀，两个空格中间切出一个空字符串。按空格切词，一般不写。

join：用连接符拼回去

join.py
words = ["red", "green", "blue"]print("-".join(words))print(" ".join(words))

join 的意思是“连起来”。点前面写连接符，括号里放列表。用 - 把三个词连起来。

换成空格当连接符。split 把句子切成列表，join 把列表拼回句子，正好相反。

▶ 在 IDE 打开
"-"red-green-blue
" "red green blue
