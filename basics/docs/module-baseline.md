# 18 个模块的内容基线

这份摘要提炼自旧仓库的 PPT，记录每个模块的核心知识、原有题目和易错点。它是做课的参考，不代表这些课已经做好，第 1 课之外都还没有新版。

重制时：

- 保留核心语义、原有例题、边界意识和难度顺序，按 [PROMPT.md](../PROMPT.md) 重写，不照搬旧 PPT 的排版和节奏。
- 部分早期模块的“独立验收”只是重写已讲题或换数据，不能直接当独立挑战，要另设一道新题。
- 条件、循环、计数、列表等模块要加逐步追踪，展示变量怎么变。
- 新加的互动、新题和开放项目是新设计，不要说成旧 PPT 已有的内容。

## 01 输入输出（已做新版）

- 核心：保存并运行 `.py`；`print()` 输出；`input()` 返回字符串；用 `int(input())` 读取整数；编辑文件时不抄 `>>>`。
- 题目：输出问候、读入名字并问候、分两行输入两个整数求和。检查 `3、4 → 7`、`-5、2 → -3` 和零。

## 02 变量与数据类型

- 核心：`=` 是赋值；变量保存当前数据；`age = age + 1` 先算右边再更新。认识 `int`、`float`、`str`、`bool`。
- 对比：`"3" + "4"` 得 `"34"`，`3 + 4` 得 `7`。逐行预测变量更新后的结果。

## 03 算术运算

- 核心：`+ - * / // %`；括号控制顺序；`float(input())` 读小数。
- 题目：长方形面积，输入 `2.5、4`，输出 `10.0`。区分 `7 / 2 = 3.5`、`7 // 2 = 3`、`7 % 2 = 1`。

## 04 条件判断

- 核心：比较运算产生真假；`if / else`；`if / elif / else`；冒号、缩进和分支对齐。
- 题目：及格判断、奇偶判断、成绩分档。检查 `59/60`、`89/90`，零也是偶数，注意多分支的顺序。

## 05 逻辑运算

- 核心：`and` 同时满足，`or` 至少一个满足，`not` 反转真假。
- 题目：判断 `score >= 60 and score < 90`，输出 `True/False`，解释为什么包含 60、不包含 90。

## 06 for 循环

- 核心：循环变量依次取值；`range` 含起点不含终点；步长和负步长。
- 题目：输出 `1～n`、筛选偶数、改成 3 的倍数、倒序输出、输出个位为 7 的数。套路是“循环枚举，判断筛选”，检查 `n=0、1、3`。

## 07 while 循环

- 核心：先判断再执行；开始值、继续条件和变量更新。
- 题目：用 `while` 重写输出 `1～n`，与 `for` 对照。用缺少 `i += 1` 的只读片段解释死循环。

> 新课把下面的 08、09 合成一节“累加和计数”，10 单独一节“最大值和最小值”。

## 08 累加器

- 核心：总和在循环前初始化为 0，每轮 `total += i`，结束后输出。
- 题目：计算 `1+2+…+n`。输入 3 时总和依次是 `1、3、6`，解释初始化和输出为什么在循环外。

## 09 计数器

- 核心：满足条件一次 `count += 1`；统计个数和计算总和不同。
- 题目：统计 `1～n` 中 3 的倍数。对 `3、6、9`，个数是 3，总和是 18。检查没有命中和 `n=0`。

## 10 最大值与最小值

- 核心：用第一个真实数据初始化，之后比较更新；读过第一项后只再读 `n-1` 项；全部比较完再输出。
- 题目：最高分 → 改成最低分 → 最高温与最低温的温差。检查单个数据、重复值和全负数，0 不是通用初值。

## 11 列表基础

- 核心：列表有顺序；`[]`、`append()`、`len()`、下标赋值；第 `k` 项的下标是 `k-1`。
- 题目：查询第 `k` 个分数 → 指定位置加分 → 从左右两端查询。检查越界、只有一个元素和首尾位置。

## 12 列表遍历

- 核心：`for score in scores` 得元素；`for i in range(len(scores))` 得下标；保存的数据可以再次遍历。
- 题目：统计及格人数 → 优秀人数 → 严格高于平均分的人数。注意 `>` 与 `>=`、小数平均分和空列表。

## 13 字符串基础

- 核心：长度、正负下标、切片、逐字符遍历；切片不含终点；字符串不能用下标赋值修改；Python 没有独立的 `char` 类型。
- 题目：首尾字符 → 前两个字符 → 指定字符出现次数。区分索引和切片对空串的处理，保留空格，注意大小写。

## 14 字符串常用方法

- 核心：`strip`、`replace`、`count`、`split`、`join`；`split()` 得列表，`join()` 得字符串；结果按需保存。
- 题目：清理逗号分隔的名字 → 改连接符 → 整理空格与连字符混合分隔的单词。
- 易错：`strip()` 不删中间空格；`split()` 与 `split(" ")` 不同；`"aaaa".count("aa")` 不重叠计数，结果是 2。

## 15 函数定义与调用

- 核心：`def` 定义函数；定义不等于执行；带括号调用才进入函数体，完成后回到调用处。
- 题目：重复输出检查步骤 → 函数体增加一步 → 定义倒数函数并调用多次。只写函数名不会调用。

## 16 参数与返回值

- 核心：参数传入数据，返回值继续参与计算；`return` 返回并结束本次调用；`print` 只是显示；没有显式返回值时返回 `None`。
- 题目：面积函数 → 周长函数 → 定义一次面积函数，调用两次求和。注意参数位置、输出位置，`return` 后的语句不执行。

## 17 常用数学函数

- 核心：`abs()` 是内置函数；用 `math.floor`、`math.ceil`、`math.sqrt` 前要导入 `math`。
- 对比：对 `-2.3`，`floor` 得 `-3`，`ceil` 和 `int` 得 `-2`；向下取整与向零截断不同。
- 题目：至少需要几个箱子 → 只统计满箱 → 给定方块数求最大正方形边长。检查整除、零和完全平方数两侧。

## 18 字典基础

- 核心：键与值；按键读取；赋值更新或新增；`in` 检查键；`get(key, default)` 给缺省值，读取时不会新增这个键。
- 题目：按商品名查价格 → 按购买数量算总价 → 统计单词出现次数。检查空数据、重复单词、未知键和大小写。
