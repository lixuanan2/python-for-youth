abs：去掉负号

abs.py
print(abs(-5))print(abs(3))a = 12b = 20print(abs(a - b))

abs 求“绝对值”：负数去掉负号，正数不变。它是 Python 自带的，直接用。

两个数差多少，不管谁大谁小，用 abs(a - b)：12 - 20 是 -8，绝对值是 8。

abs(3)3

import math：借工具

math_tools.py
import mathprint(math.sqrt(16))print(math.floor(4.6))print(math.ceil(4.6))

import 的意思是“导入”。math 是一盒数学工具，导入以后用“math.名字”。sqrt 开平方：4 × 4 = 16。

floor 是“地板”，向下取整：4.6 变成 4。

ceil 是“天花板”，向上取整：4.6 变成 5。

▶ 在 IDE 打开
sqrt4.0
floor4
ceil5

▶ 在 IDE 验证

猜一猜：-2.3 往哪边取？

floor 往下

math.floor(-2.3)

-3

ceil 往上

math.ceil(-2.3)

-2

int 去掉小数

int(-2.3)

-2

在数轴上，-3 在 -2.3 的左边，-2 在右边。

floor 永远往数轴左边走，所以是 -3，不是 -2。int 只是把小数部分砍掉，往 0 靠。
正数时 floor 和 int 一样；碰到负数就不一样了。

程序不认识 math，报 NameError。工具盒要先借来，才能用里面的工具。
import math 写在程序第一行，后面整个程序都能用。abs 不用 import，它是 Python 自带的。
