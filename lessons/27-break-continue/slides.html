循环原来只会从头转到尾。有时我们想在中间就停下：找到了就别再找，输对了就别再问。
这节课学两个词：break 是“跳出”，整个循环马上结束；continue 是“继续”，跳过这一次，直接进下一圈。

break：马上跳出循环

break.py
for i in range(1, 10):    if i * i > 30:        break    print(i)print("停在", i)

i 从 1 到 5，i * i 都不超过 30，不进 if，照常输出。

i 是 6 时，36 超过 30，运行 break：循环马上结束，7、8、9 都不再试。跳到循环后面那一行。

第 22 课的例题，换个写法

retry.py
while True:    try:        age = int(input())        break    except ValueError:        print("不是整数，再输一次")print("明年你", age + 1, "岁")

转换成功，才走到 break；出错就跳到 except，break 被跳过，接着再问。
不用 done 记着，读起来就像在说：一直问，输对了就停。

continue：跳过这一次

skip.py
for i in range(1, 11):    if i % 3 == 0:        continue    print(i)

1 和 2 不是 3 的倍数，不进 if，照常输出。

i 是 3 时运行 continue：剩下的 print 不做了，直接去下一圈。6 和 9 也被跳过。
break 是整个循环结束，continue 只跳过这一次。
