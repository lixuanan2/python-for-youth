f-string：把话说得整整齐齐

学完你能把变量直接放进句子里，让小数只留两位，把时间显示成 01:05:09。

输出总是不太整齐

明年你 13 岁
print(10 / 3)
3.3333333333333335

逗号会多出空格，小数又长得看不完。写成绩单、小票、时钟，都想要整整齐齐的输出。
这节课学 f-string：在引号前面加一个 f，就能把变量直接写进句子里，还能管住小数有几位。

引号前面加 f

hello.py
name = "小明"age = 12print(f"{name}今年{age}岁")print(f"明年{age + 1}岁")

f 是 format（格式）的第一个字母。加了 f，引号里的大括号 { } 就会换成变量的值。没有逗号，也就没有多余的空格。

大括号里还能写算式。{age + 1} 先算出 13，再放进句子里。

猜一猜：忘了写 f，会输出什么？

hello.py
name = "小明"age = 12print("{name}今年{age}岁")

只少了一个字母 f。
会报错吗？

{name}今年{age}岁

不报错，原样输出。没有 f，它就是一串普通的文字，大括号也只是普通的符号。
看到屏幕上出现大括号，先检查引号前面有没有 f。

冒号后面管小数有几位

decimal.py
x = 10 / 3print(x)print(f"{x:.2f}")print(f"{x:.1f}")

直接输出，小数长得看不完。最后那个 5 是计算机存小数时留下的一点点误差。

大括号里加 :.2f，意思是“按小数显示，保留 2 位”，会四舍五入。:.1f 就是保留 1 位。只改显示的样子，x 本身没变。

例题：打印一张小票

receipt.py
price = float(input())count = int(input())total = price * countprint(f"{count} 件，每件 {price:.2f} 元")print(f"一共 {total:.2f} 元")

输入单价 3.5 和件数 4。单价可能有小数，用 float()；件数是整数，用 int()。总价是 14.0。

一句话里可以放好几个大括号。件数照常显示，单价按 2 位小数显示：3.50。

14.0 也按 2 位显示成 14.00。钱数都是两位小数，小票看着就整齐了。

不够两位，前面补 0

time.py
m = 5s = 9print(f"{m}:{s}")print(f"{m:02d}:{s:02d}")

5 分 9 秒，直接输出成 5:9，不像钟表上的样子。

:02d 的意思是“整数，至少 2 位，不够前面补 0”。d 表示整数。12 本来就有两位，就不补。

▶ 在 IDE 打开
