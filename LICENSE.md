# 许可

这个仓库里的东西分三类，许可不同。

| 内容 | 位置 | 许可 |
| --- | --- | --- |
| 课件内容 | 各模块 `lessons/` 里的页面和题目、`docs/`、`PROMPT.md`、`dist/` 里的课件，最外层的 `README.md` 和 `home/` 网站首页 | [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans) |
| 代码 | 各模块的 `tools/`、`template/`、`lessons/` 里的 `.py` 程序，`.github/workflows/` | MIT，全文见下 |
| 第三方内容 | 各模块的 `vendor/` | 各自的许可，见 `vendor/` 里的许可文件 |
| GitHub 图标 | `basics/template/icons/github.svg` | 属于 GitHub，只用来链接到 GitHub，不在上面的许可内 |
