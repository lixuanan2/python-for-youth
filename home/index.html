青少年编程

Free, open Python courseware in Chinese for upper-primary and middle-school students (about ages 10 to 15). Each lesson is a web page that opens offline with a double-click, reads well enough for self-study, and sends any code on the page to an online IDE in one click. Teachers, schools and anyone who wants to collaborate are welcome to get in touch through GitHub Discussions.

这是一套给小学高年级和初中生的 Python 课件，免费、开源。每节课是一个网页，老师拿来上课，学生也能照着自学。

有什么不一样

  • 离线双击就能打开每节课是一个网页文件，样式、脚本和字体都在里面，不用装软件，不用联网。只有打开 IDE 和官方文档时要联网。
  • 学生能照着自学每节课按“讲一点、练一点”推进：先猜结果再揭晓，选择小测点了马上解释，点出报错的那一行，最后做一个自己定主题的小程序，再和同桌换着玩。
  • 代码一键进在线 IDE页面上的代码点一下就带到 JupyterLite 里运行，动手题带着起始程序打开，不用复制粘贴。
  • 黄色框能在页面上直接改值只改一个数、结果一眼能看到的地方，学生在页面上改 7，结果马上变，省掉打开 IDE 的时间。
  • 每个程序和页面说法都有自动检查页面上的程序都由工具检查过：页面说的输出和报错用真实 Python 运行核对，个别停不下来的示例只检查写法、不运行；题目答案用测试数据跑过，动手题和挑战的答案不会出现在学生拿到的文件里。每次改动后，每一页还会在真实的 Chrome 里打开，检查排版、小测、黄色框和 IDE 链接。

怎么用

在线

在这个网站上选一节课，直接放映。

教室电脑

在 GitHub 仓库的页面点 Code → Download ZIP，解压后把 basics/dist 文件夹整个复制到教室电脑，双击里面的 index.html。这个文件夹里有课件、PDF 和起始程序，没有答案。

放映时按 → 或空格翻页，R 带着本页代码打开 IDE，F 全屏，? 查看全部快捷键。

用 Edge 的话

IDE 里的 Python 是在浏览器里跑的。Edge 开着“增强的安全性”时会关掉它要用的功能，表现是点了运行右边一直空白。在 Edge 设置里搜“增强的安全性”，在“例外”里添加 jupyterlite.github.io 就好了；或者改用 Chrome。
